# Calculations and Units

## Rule

For numeric work, verify calculations with a reliable method or tool when available.

Use `tools/calculation-verification.md` for:
- multi-step calculations,
- unit conversions,
- formulas with several variables,
- clinical, financial, engineering, or academic calculations,
- symbolic or algorithmic calculations,
- any result where a decimal, sign, unit, or magnitude error would matter.

## Output

- Give the numerical answer first.
- Include units.
- Show essential working only.
- Check sign, decimal placement, and magnitude.
- For subtraction, compare values first to determine the correct sign.

## Unit checks

Always verify:
- unit compatibility,
- conversions,
- significant figures when relevant,
- whether the result is physically or clinically plausible.

## Formula discipline

Before calculating:
- identify the formula or relationship,
- define each variable,
- confirm units,
- substitute values carefully,
- check the result against an estimate or limiting case.

If there are multiple possible formulas, explain which one applies and why.

## Error prevention

Check specifically for:
- sign errors,
- denominator/reciprocal errors,
- percentage versus decimal errors,
- degrees versus radians,
- metric prefixes,
- rounding too early,
- hidden assumptions in averages, rates, or ratios.

## Uncertainty

If input values are approximate, state that the answer is approximate.
