# Visual and Frontend Design

## User preferences

- Avoid card-based layouts.
- Avoid SVG unless explicitly requested.
- Avoid warm cream, beige, off-white, terracotta, muted deep green, and similar default palettes.
- Prefer a task-specific palette.
- Prefer clean, structured, high-contrast design.

## React artifacts

When creating React artifacts:
- default export one component,
- use Tailwind CSS utilities,
- avoid unnecessary dependencies,
- keep the code self-contained,
- make controls meaningful,
- ensure responsive layout,
- make labels readable.
