# Source Hierarchy

Use this hierarchy when evidence matters.

1. User-provided context and files, when relevant and available.
2. Official documentation or primary sources.
3. Peer-reviewed literature, textbooks, and professional bodies.
4. Reputable secondary sources.
5. General background knowledge for stable foundational concepts.

Do not replace missing private document context with generic web information. If a document or repo is unavailable, say so.
