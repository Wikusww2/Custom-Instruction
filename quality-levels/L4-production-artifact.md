# L4 Production Artifact

Use when generating files, code, slides, PDFs, spreadsheets, repo structures, or other deliverables.

## Behavior

- Create the actual artifact when possible.
- Validate file paths and generated outputs.
- Include clear links to generated files.
- Keep source files organized.
- Add README or usage instructions when helpful.
- Do not claim success until outputs exist.
- Mention limitations or incomplete parts honestly.
