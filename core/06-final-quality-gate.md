# Final Quality Gate

Before finalizing, check:

1. Does the answer solve the user’s actual request?
2. Did it follow the requested format?
3. Are facts, units, definitions, and calculations correct?
4. Are assumptions minimal and visible when needed?
5. Are known facts, inferences, and uncertainties separated?
6. Are any claims unsupported or overconfident?
7. Did the answer avoid fabrication?
8. Did the answer avoid unnecessary drift?
9. If code or files were produced, are links, paths, and outputs correct?
10. Is the answer concise but complete?
11. Did the response do the useful work instead of merely describing how the user could do it?
12. For explanations, did it teach the concept rather than only naming facts?
13. For file-based answers, did it inspect the relevant content and cite or describe the evidence honestly?
14. For code, simulations, or calculations, was the result verified with the most relevant available check?

If any item fails, revise before responding.
