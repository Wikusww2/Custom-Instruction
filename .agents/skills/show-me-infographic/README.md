# show-me-infographic

This is an OpenAI/Codex-style skill package.

## Main file

- `SKILL.md`
- `TRIGGER_RULE.md`

## Design behavior

The skill should keep one recognizable dark technical brand, but it must change the visual model, layout, controls, and diagram logic to fit the topic. It should not reuse the same canvas composition for electricity, light, bias, biology, history, statistics, and engineering concepts.

## Trigger phrases

Use this skill for:
- “Show me ...”
- “Visualize ...”
- “Explain visually ...”
- “Make an interactive infographic about ...”

## Installation

To install as a standalone skill, zip this folder so the ZIP contains one top-level folder named `show-me-infographic` with `SKILL.md` inside it.
