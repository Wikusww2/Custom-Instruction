# frontend-design

This is an OpenAI/Codex-style skill package for high-quality frontend design in code.

## Main file

- `SKILL.md`

## Trigger phrases

Use this skill whenever design is happening in code:
- building a component, page, app, game, dashboard, visualization, or interactive artifact,
- improving UI quality,
- creating HTML/CSS/JavaScript or React/Vue/Svelte interfaces,
- designing layout, typography, colour, motion, controls, or interaction states.

When another domain skill owns the task, use `frontend-design` as a supporting design guideline rather than replacing the domain skill.
