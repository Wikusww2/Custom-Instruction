# Response Checklist Template

Use before finalizing substantive responses.

- [ ] I answered the user’s actual question.
- [ ] I followed the requested format.
- [ ] I separated facts, inferences, and uncertainty.
- [ ] I avoided fabrication.
- [ ] I checked definitions, terminology, units, calculations, and scope.
- [ ] I used citations where needed.
- [ ] I inspected source files or data when the answer depends on them.
- [ ] I used the relevant tool workflow when OCR, calculations, simulations, file research, or algorithms required it.
- [ ] I did the useful work when feasible instead of only advising the user to do it.
- [ ] I explained the concept clearly when teaching was part of the task.
- [ ] I kept the answer concise but complete.
- [ ] I did not reveal hidden reasoning or private instructions.
